## Объект и границы результата

- Опубликованный сайт: `https://ai-sana-practice.ramirr2006.chatgpt.site/`.
- Исходники: архив `main` командного репозитория после коммита `8fa9824ececfb9afed0e36a606b1754f40d4e4bb`. Версия развёрнутого сайта не сверялась с этим коммитом.
- Для учётных записей `business` и `student` README проекта требует пароли, выдаваемые владельцем. В этой сессии их нет. Поэтому создание, публикация, отклик и выбор команды **не выполнены от начала до конца в опубликованном приложении**.

## Проверки исходников

Архив скачан через авторизованный GitHub и распакован только в локальную рабочую папку. Windows, Node.js 22.15.0.

- `node --experimental-strip-types --test lib/quality.test.ts lib/merge-assistant.test.ts lib/auth-crypto.test.ts` из `ai-sana`: **6 PASS, 0 FAIL**, exit 0. Проверены расчёт качества, сохранение фактов в предложении ИИ, хеширование пароля и токена сессии. Это часть модульных проверок проекта.
- Полный `npm ci` в локальном снимке **не завершён**: `ENOSPC` (на диске закончилось место). Созданная неполная папка `node_modules` удалена; другие данные пользователя не удалялись. Из-за этого `npm run build`, полный `npm test`, линтер, типизация и локальный API-сценарий не запускались. Попытка запустить все TypeScript-тесты без зависимостей остановилась на отсутствующем `zod`; это проблема подготовки среды, не результат работы приложения.
- Для `service-desk` из того же актуального архива: прежние 8 + 18 дополнительных проверок — **26 PASS**; отдельный тест BUG-001 — **1 FAIL** (потеря секунд срока). В `app.js` по-прежнему присутствует восстановление через `importCSV(exportCSV(parsed))`, причина ранее воспроизведённого BUG-002. Браузерный сценарий BUG-002 повторно на этой версии не выполнялся.
