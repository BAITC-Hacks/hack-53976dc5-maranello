## Запуск service-desk

Node.js 20 или новее, без установки зависимостей. Из корня репозитория:

```sh
cd "тестирование сайта"
node --test ../service-desk/core.test.mjs qa-hour-01.test.mjs
node --test qa-known-bugs.test.mjs
node qa-stage-02-fixtures.mjs
```

Первая проверка: 26 PASS. Вторая пока завершается с кодом 1 из-за BUG-001; она проверяет ожидаемое правильное поведение. Генератор создаёт CSV в .qa-stage-02/ для ручного выполнения браузерных сценариев.
