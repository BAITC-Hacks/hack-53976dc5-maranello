# Тестирование сайта

Материалы QA для учебной панели **service-desk**. Основной модуль **ai-sana** этим прогоном не проверялся.

## Результаты на 23 сентября 2026

- 26 модульных проверок прошли: 8 исходных и 18 дополнительных.
- Отдельный тест BUG-001 падает: при импорте теряются секунды срока.
- 12 браузерных сценариев: 10 прошли, 2 выявили BUG-002 — изменение ID после перезагрузки и дубликат при повторном импорте.
- Оба дефекта пока не исправлены. Код приложения не менялся.

## Запуск

Node.js 20 или новее, без установки зависимостей. Из корня репозитория:

```sh
cd "тестирование сайта"
node --test ../service-desk/core.test.mjs qa-hour-01.test.mjs
node --test qa-known-bugs.test.mjs
node qa-stage-02-fixtures.mjs
```

Первая проверка: 26 PASS. Вторая пока завершается с кодом 1 из-за BUG-001; она проверяет правильное ожидаемое поведение. Генератор создаёт CSV в .qa-stage-02/ для ручного выполнения браузерных сценариев.

Тесты импортируют настоящий ../service-desk/core.js. Эти материалы опубликованы отдельной папкой; предыдущие материалы в QA-ветке и PR №1 сохранены.

## Оставшийся подход

Сквозная проверка основного AI Sana: создание задания → оценка качества → публикация → отклик студента → выбор бизнесом. Затем итоговый отчёт перед сдачей и повторная проверка исправленных дефектов. Этот подход ещё не выполнялся.
