# Поток — панель заявок клиентов

Решение учебного задания [AI Sana: «Панель для обработки заявок клиентов»](https://ai-sana-practice.ramirr2006.chatgpt.site/?view=detail&task=example).

## Запуск

Требуется Node.js 20 или новее. Установка пакетов не нужна.

```sh
cd service-desk
npm start
```

Откройте http://127.0.0.1:4173. Для другого порта задайте переменную окружения `PORT`.

## Возможности

- При первом запуске загружаются 50 обезличенных заявок из `example.csv`.
- Статус и ответственный меняются прямо в таблице и сохраняются после перезагрузки.
- Фильтры: активные, просроченные, ответственный, статус; поиск по номеру, теме и категории.
- Просрочена только активная заявка, чей срок ответа уже прошёл; решённые и отменённые исключаются.
- Сводка показывает активные, новые, решённые и просроченные заявки; блок команды — загрузку менеджеров.
- Импорт CSV добавляет новые номера и обновляет существующие, сохраняя остальные заявки. Повторный импорт не создаёт дубликаты при стабильных номерах.
- Экспорт включает все заявки, независимо от фильтров.

## CSV

UTF-8, запятая или точка с запятой, кавычки и многострочные поля поддерживаются. Пример: `example.csv`.

| Поле | Русский заголовок | Правило |
|---|---|---|
| id | номер | Необязательно; уникальный номер. Рекомендуется для повторного импорта. |
| date | дата | Обязательно: `2026-09-23` или `2026-09-23T10:00`. |
| title | тема | Необязательно; иначе формируется из категории. |
| category | категория | Обязательно. |
| assignee | ответственный | Обязательно; новые имена появляются в списках. |
| status | статус | Новая, В работе, Решена или Отменена. |
| due | срок ответа | Необязательно; по умолчанию 18:00 следующего дня. |

Все даты интерпретируются в местном часовом поясе браузера. Импорт некорректного файла отклоняется целиком с номером строки. Лимит — 2 МБ. Без `id` номер формируется из даты и позиции записи: перестановка строк может изменить номера. Экспорт обезвреживает начальные символы формул электронных таблиц, добавляя апостроф.

## Хранение и границы прототипа

Данные сохраняются в `localStorage` этого браузера для этого адреса. Между компьютерами и браузерами автоматической синхронизации нет. Для переноса используется CSV. Несколько вкладок одного браузера получают изменения через событие `storage`; одновременная запись действует по правилу последней записи. Это прототип, не многопользовательская CRM: нет сервера данных, авторизации, отправки сообщений и интеграций. Использовать только обезличенные данные. Демодаты фиксированы на сентябрь 2026 года, поэтому количество просроченных меняется со временем.

## Проверка

```sh
npm test
```

8 автоматических тестов: импорт 50 записей и обратный экспорт, CSV с BOM/кавычками/переносами, просрочка и закрытые статусы, повторный импорт, неверные строки и даты, минимальный CSV, сочетание фильтров, защита экспорта от формул.

В браузере: изменить статус и ответственного, перезагрузить страницу и убедиться, что изменения сохранились. Затем импортировать пример CSV и проверить сообщение «Импортировано: 50».

## Структура

`index.html`, `style.css`, `app.js`, `core.js`, `example.csv` — готовое статическое приложение. `server.mjs` — локальный HTTP-сервер. `core.test.mjs` — тесты без сторонних зависимостей. В браузерах с WebMCP доступны чтение заявок и изменение статуса/ответственного; обычный интерфейс работает без WebMCP.
