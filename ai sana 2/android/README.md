# AI Sana · Android MVP

Приложение открывает https://ai-sana-practice.ramirr2006.chatgpt.site/ в Android WebView. Данные, ИИ и аккаунты общие с сайтом. Нужен интернет и Android 8.0 или новее.

## Установка

Передайте AI-Sana.apk на Android-телефон, откройте его и установите. Если система попросит разрешение для установки APK из выбранного файлового менеджера, подтвердите его самостоятельно. Приложение не опубликовано в Google Play.

Для входа внутри приложения используйте логин `business` или `student` и выданный пароль. Пароли не встроены в APK и не включены в исходники. Вход через ChatGPT откроется во внешнем браузере; его сессия не переносится обратно в WebView.

## Возможности оболочки

- Иконка и отдельное окно приложения.
- Кнопки назад, обновления и открытия текущей страницы в браузере.
- Сохранение сессии через cookies, экран ошибки сети с повтором.
- HTTPS, запрет mixed content и доступа WebView к локальным файлам, без JavaScript-моста и встроенного API-ключа.
- Единственное разрешение Android: интернет.

## Проверка

APK скомпилирован, подписан; подписи v2 и v3 проверены библиотекой Google apksig. Проверены manifest, activity запуска и выравнивание resources.arsc. APK не запускался на эмуляторе или физическом устройстве в этой среде.

На телефоне остаётся проверить: запуск; business → «Мои задачи»; видимость отклика; выход и вход student; работа клавиатуры; кнопка назад; перезапуск приложения; экран ошибки без сети и повтор после восстановления.

## Сборка исходников

Откройте папку как проект Android Studio. Установите Android SDK Platform 35 и совместимые инструменты по запросу Android Studio. Проект использует Android Gradle Plugin 8.13.2 и Java 8 language level (для запуска Gradle нужен JDK 17+). Соберите APK через Build → Generate App Bundles or APKs → Generate APKs. Проект не требует сторонних библиотек времени выполнения.

Для данного APK использовались отдельные компиляторы AAPT2/D8 и библиотека apksig из Google Maven; Android API 35 для компиляции предоставлен android-all из Maven Central. Эти инструменты и Android API jar не входят в APK.

Подпись демонстрационная. Закрытый ключ сохранён отдельно от проекта и GitHub. APK, собранный Android Studio с другим ключом, не установится поверх этой версии: потребуется исходный ключ либо удаление старой установки (с потерей локальной сессии).

Документация инструментов: https://developer.android.com/tools/aapt2 и https://developer.android.com/tools/apksigner
