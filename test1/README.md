# AI Sana — платформа бизнес-задач

MVP для хакатона по геймификации практических заданий. Бизнес описывает задачу и публикует карточку с рейтингом готовности; студенческие команды находят задачу в открытом каталоге, отправляют предложение, а бизнес вручную принимает решение по отклику.

## Запуск

```bash
source venv/bin/activate
streamlit run app.py
```

Для AI-вызовов задайте `OPENAI_API_KEY`. Без ключа приложение использует локальные вопросы и сборку черновика карточки; отсутствующие факты остаются пустыми. Сформированную карточку нужно проверить и подтвердить перед публикацией.

## Возможности MVP

- Пошаговое описание задачи, минимум три уточняющих вопроса и редактирование карточки до публикации.
- Оценка полноты из 100 баллов с расшифровкой и подсказками по незаполненным полям.
- Открытый каталог с сортировкой, фильтрами по теме и уровню готовности; низкий рейтинг не скрывает задачу и не блокирует отклики.
- Профили команд с интересами и навыками, тематические рекомендации без ограничения каталога.
- Отклики с идеей, планом, сроком и ссылкой. Бизнес вручную принимает или отклоняет каждое предложение.
- Пять синтетических карточек задач, профилей команд и откликов для демонстрации.

## Формула рейтинга

| Поле | Баллы |
|---|---:|
| Контекст и потребность | 20 |
| Данные и материалы | 20 |
| Ожидаемый результат | 15 |
| Критерии успеха | 15 |
| Ограничения | 10 |
| Пользователи | 10 |
| Связь с бизнесом | 10 |

Уровни: 0–39 — черновик; 40–69 — рабочая; 70–89 — готовая; 90–100 — приоритетная. Баллы начисляются за заполненные поля и пересчитываются во время редактирования карточки.

## Данные и ограничения

Данные MVP хранятся в Streamlit session state и сбрасываются при перезапуске сессии. Регистрация, сложная ролевая модель, чат, уведомления и автоматическое назначение исполнителей не реализованы и не требуются для демонстрационного объёма.

Полное структурированное ТЗ находится в [specification.md](specification.md).
