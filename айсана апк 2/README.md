# AI Sana — Android 1.1

**Бизнес формулирует. Студенты выбирают.**

[Скачать APK](./AI-Sana.apk) · [Открыть веб-версию](https://ai-sana-practice.ramirr2006.chatgpt.site/) · [Исходники Android](./android-source.zip) · [Исходники веб-приложения](./web-source.zip)

## 1. Название проекта

**AI Sana** — MVP для практического хакатона HackAlem AI. Эта папка содержит Android-приложение версии **1.1**, `versionCode 2`, пакет `kz.aisana.practice`. Требуется Android 8.0 или новее и интернет.

## 2. Проблема и аудитория

Первоначальное описание бизнес-задачи часто не объясняет проблему, результат и условия работы. Студентам трудно оценить объём задачи и предложить подходящее решение.

AI Sana помогает представителю бизнеса подготовить понятную карточку и увидеть пробелы в описании. Студенческие команды самостоятельно выбирают проекты из открытого каталога и отправляют предложения. Бизнес решает, с какой командой продолжить работу.

## 3. Что реализовано

- Карточка задачи с тремя этапами заполнения, черновиком и публикацией.
- Объяснимый рейтинг полноты описания 0–100; подробные задачи выше в каталоге.
- Проверка заглушек, однообразных повторов и почти одинакового текста в ключевых полях.
- Поиск, фильтры по навыкам и статусу; кабинеты бизнеса и студента.
- Отклик команды из 3–5 разных участников, просмотр предложений владельцем и ручной выбор команды.
- Сохранение в базе данных, разграничение доступа и контроль версии при редактировании.
- Парольные аккаунты бизнеса и студента; в браузере также предусмотрен вход через ChatGPT.
- GPT-помощник с просмотром и выборочным применением предложений. Заполненные поля бизнеса сохраняются.
- Цитаты из исходного описания рядом с предложениями ИИ. Фактические разделы заполняются найденными цитатами; ИИ предлагает название, резюме и навыки.
- Резервная копия несохранённых полей в текущей вкладке и восстановление после перезагрузки.
- Автоматическое обновление откликов и статуса выбора; безопасный повтор одинаковой отправки после обрыва связи.

Android-приложение — WebView-оболочка опубликованного сайта с кнопками «Назад», обновления и открытия в браузере, индикатором загрузки и экраном повторной попытки при сетевой ошибке. Для обновления веб-функций переустановка APK не требуется.

## 4. Как работает решение

1. Бизнес входит и описывает потребность своими словами.
2. По желанию отправляет описание GPT. Помощник предлагает структуру и уточняющие вопросы.
3. Бизнес проверяет предложения, отмечает нужные поля и дополняет условия. Рейтинг пересчитывается по одним правилам на клиенте и сервере.
4. Карточка сохраняется как черновик или публикуется в каталоге.
5. Студент входит под своим аккаунтом, выбирает задачу и отправляет название команды, участников и план работы.
6. Владелец задачи видит предложение и подтверждает выбор команды. Приём новых откликов завершается.

Команды не назначаются автоматически. Рейтинг описания не оценивает людей и не подтверждает ценность идеи.

## 5. Технологии

| Компонент | Реализация |
|---|---|
| Android | Java, Android Activity и WebView; min SDK 26, compile/target SDK 35 |
| Конфигурация Android | Android Gradle Plugin 8.13.2, Java 8 source compatibility |
| Интерфейс | React 19, TypeScript, Lucide, CSS |
| Веб-сборка | Vinext, Vite, маршруты Next App Router |
| Сервер | Cloudflare Workers |
| Данные | Cloudflare D1 / SQLite, Drizzle для схемы и миграций |
| Проверка данных | Zod, общая функция расчёта рейтинга |
| ИИ | OpenAI Responses API, строгая JSON Schema; модель по умолчанию `gpt-4.1-mini`, переопределяется `OPENAI_MODEL` |

## 6. Архитектура

```text
Android Activity → WebView → опубликованный React-интерфейс
                                 ↓
Браузер → тот же интерфейс → серверные маршруты API
                                 ├─ сессия, роль, владелец, проверка данных
                                 ├─ правила качества → рейтинг
                                 ├─ подготовленные SQL-запросы → D1
                                 └─ описание и черновик → OpenAI → проверка цитат
```

В архиве `web-source.zip`: `app/components/` — экраны; `app/api/` — API; `lib/assistant.ts` — GPT и проверка источников; `lib/quality.ts` — рейтинг; `lib/repository.ts` — операции базы; `lib/draft-recovery.ts` — восстановление; `db/` и `drizzle/` — схема и миграции.

Ключ OpenAI используется на сервере. APK и клиентский JavaScript не содержат ключа. Парольные сессии используют HttpOnly cookie; сервер хранит хэш токена. Резервная копия формы хранится в `sessionStorage`, отдельно для пользователя и задачи.

## 7. Установка и запуск

### Установить APK

1. Скачайте `AI-Sana.apk` на Android 8.0+.
2. Откройте файл и разрешите установку из выбранного источника, если Android попросит.
3. Запустите **AI Sana** при подключённом интернете.
4. Войдите в предоставленный аккаунт бизнеса или студента. Пароли передаются отдельно.

Версия 1.1 подписана тем же ключом, что и ранее выложенная 1.0, и имеет более высокий код версии. При обычной установке она предназначена для обновления поверх прежнего приложения. Обновление на физическом устройстве пока не проверено.

Через Android Platform Tools:

```bash
adb install -r AI-Sana.apk
```

Контрольная сумма находится в `AI-Sana.apk.sha256`.

### Запустить веб-приложение локально

Распакуйте `web-source.zip`, откройте каталог `ai-sana`. Требуются Node.js 22.13+ и npm; проверки выполнены на Node.js 24.20.

```bash
npm ci
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_friendly_crusher_hogan.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_concerned_may_parker.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0002_kind_tarantula.sql
node scripts/create-demo-accounts.mjs ../private-accounts.json
```

Эти команды миграций предназначены для новой локальной базы. Скрипт создаст локальные аккаунты и запишет случайные пароли в `../private-accounts.json`, а конфигурацию аккаунтов — в `.dev.vars`. Сохраните файл с паролями вне репозитория. Не запускайте создание аккаунтов поверх уже настроенных.

```bash
npm run dev
npm test
npm run typecheck
npm run build
```

При отсутствии `OPENAI_API_KEY` ручное заполнение, рейтинг, публикация и отклики работают. Для реального ИИ задайте ключ в серверном окружении; не добавляйте `.dev.vars` в Git.

### Пересобрать Android

Распакуйте `android-source.zip`, установите JDK 17+, Android SDK Platform 35 и совместимый Gradle. Укажите SDK в `ANDROID_HOME` или `local.properties`, затем из каталога проекта выполните:

```bash
gradle assembleDebug
```

Gradle Wrapper в архив не включён. Debug-сборка будет подписана локальным debug-ключом и не является заменой опубликованного APK для установки поверх него. Поставленный APK собран средствами `aapt2`, `javac`, D8 и подписан библиотекой `apksig`; приватный ключ подписи не распространяется.

## 8. Как проверить решение

1. Откройте сайт или APK, войдите как бизнес и создайте задачу с пометкой `[ТЕСТ]`.
2. Введите: «У нас сервисная компания. Менеджеры ведут заявки в нескольких таблицах, теряют обращения и забывают отвечать клиентам. Хотим видеть статус, ответственного и срок ответа в одном месте. Срок проекта пока не определён».
3. Нажмите «Помочь с описанием», проверьте цитаты, снимите отметку с одного поля и примените выбранное. Снятое поле должно остаться пустым.
4. Дополните проблему, желаемый результат, данные, аудиторию, результат передачи, сроки и критерии проверки. Сохраните черновик.
5. Измените название без сохранения, перезагрузите страницу и нажмите «Восстановить». Новое название должно вернуться. Сохраните его.
6. Опубликуйте задачу, затем войдите как студент. Отправьте предложение команды из трёх участников с конкретным планом.
7. Войдите как бизнес, откройте свою задачу в «Мои задачи» и выберите команду. Перезагрузите страницу — решение должно сохраниться.
8. Под студентом проверьте результат в «Мои отклики» или карточке задачи.

**Проверено для этой версии:** 19 автоматических тестов логики; 16 локальных API-проверок с двумя отдельными аккаунтами; TypeScript и production build; реальные ответы OpenAI; выборочное применение в браузере; восстановление после первого сохранения, редактирования и перезагрузки; экран шириной 390 px без горизонтального переполнения. Проверены подпись APK и метаданные версии. На эмуляторе и физическом Android APK не запускался.

## 9. Данные и интеграции

Источник бизнес-задач — пользовательский ввод. Карточки, отклики, сессии и лимиты хранятся в D1. Владелец видит отклики на свои задачи; студент — свои предложения.

OpenAI получает описание и текущий черновик только по нажатию кнопки. Используются `store: false`, таймаут 45 секунд и лимит 10 попыток на пользователя в час. Это не обещание полного отсутствия хранения данных у провайдера. Не отправляйте секретные сведения.

Учебные примеры обозначены как примеры. Внешнего датасета, RAG, обучения собственной модели, CRM-интеграции и импорта CSV в самой платформе нет. Контактная почта открывается через `mailto:`; адреса тестовых аккаунтов `@demo.invalid` вымышленные.

## 10. Ограничения

- Для APK нужен интернет; это оболочка веб-приложения, а не отдельный офлайн-клиент.
- Приложение не опубликовано в Google Play и не испытано на физическом Android.
- Вход через ChatGPT в APK открывает внешний браузер; сессия не переносится в WebView. Внутри APK используйте парольные аккаунты.
- Нет самостоятельной регистрации, восстановления пароля, чата, push/email-уведомлений, загрузки файлов и удаления задач через интерфейс.
- Рейтинг проверяет полноту текста; он не доказывает достоверность, полезность или выполнимость задачи.
- ИИ может ошибиться в названии, резюме, навыках или выборе раздела для цитаты. Бизнес проверяет итоговую карточку.
- Резервная копия действует в той же вкладке до 24 часов; после её закрытия и на другом устройстве нужен серверный черновик. История изменений не ведётся.
- Один отклик студента на задачу; участники команды записываются текстом. Выбор команды нельзя отменить через интерфейс.
- Каталог ограничен 500 свежими записями. Нет пагинации и рекомендаций по профилю.
- Нет подтверждённых метрик внедрения у реальных компаний. Победа на хакатоне не гарантируется.
